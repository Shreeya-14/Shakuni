# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

The Shakuni development team takes security and ethical safety seriously.

If you discover a security vulnerability or exploit within this repository (such as API injection vulnerabilities, Denial-of-Service vectors, or insecure dependency configurations):

1. **Do not create a public issue**.
2. Email the maintainers directly at `security@shakuni-project.local` (or file a private GitHub Advisory).
3. Include:
   - Description of vulnerability
   - Steps to reproduce
   - Potential impact
   - Proposed mitigation (if known)

We will respond within 48 hours to validate the report and work on a coordinated fix.

## Ethical Safety & Adversarial Use

Because Shakuni analyzes manipulation and persuasion patterns, researchers studying evasion attacks or adversarial text perturbing are encouraged to submit their findings responsibly. Automated scoring systems must not be used in high-stakes environments without independent human review.
